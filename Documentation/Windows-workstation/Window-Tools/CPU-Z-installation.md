# Installing CPU-Z onto Workstation

## Objective
- Install CPU-Z as a hardware identification and system monitoring utility within the Windows lab environment.
- Develop experience using diagnostic tools to collect hardware specifications and verify system configurations.
- Practice documenting troubleshooting and inventory tools commonly used in enterprise IT support environments.

---

## Prerequisites
- Windows client or server operating system installed and operational
- Local administrator account access
- Internet access to download the installer
- Approved software source for obtaining the installation package

---

## Environment
Host: MacBook Air (M2, 8 GB RAM)
Client Windows 11 Pro ARM Virtual Machine
Server:None (planned for future phases)
Cloud: none
OS: Windows 11 Pro ARM
Tools:

---
## Procedure

1.  Open browser in Windows
2. Go to CPU-Z official website
3. Scroll to download options
4. Click download setup
5. Open Installer
6. Continue window setup

  
---  
  
## Verification  
  
1.  After installation click start and open CPU-Z
2. Should display info abt processor
- Confirm CPU-Z appears under Installed Programs.
- Launch CPU-Z successfully.
- Verify CPU-Z displays system hardware information.
- Compare CPU-Z information with Windows System Information and Device Manager.
- Confirm the tool can be used for future troubleshooting and hardware inventory tasks
