# INstalling HWMonitor onto Workstation

## Objective / Purpose

- Install HWMonitor as a hardware monitoring utility for observing system temperatures, voltages, fan speeds, and hardware sensor information.
- Develop troubleshooting skills by learning how to collect hardware performance data.
- Practice using monitoring tools that support system health checks and hardware diagnostics.

---

## Prerequisites

- Windows client or server operating system installed and operational
- Local administrator account access
- Internet access to download the installer
- Approved software source for obtaining the monitoring utility

---

## Environment

Host: MacBook Air (M2, 8 GB RAM)  
Client: Windows 11 Pro ARM Virtual Machine  
Server: None (planned for future phases)  
Cloud: None

OS:

- Windows 11 Pro ARM

Tools:

- HWMonitor
- Windows Task Manager
- Windows Resource Monitor
- Device Manager

---

## Procedure

1. Download the appropriate HWMonitor installer package for Windows.
2. Run the installer with administrator privileges.
3. Accept the license agreement.
4. Select the installation directory.
5. Complete the installation wizard.
6. Launch HWMonitor from the Windows Start Menu.
7. Review available hardware monitoring information:
    - CPU temperatures
    - CPU voltage
    - Memory information
    - Storage information
    - Fan speeds (if available)
8. Record relevant system health information for documentation.

9. Open browser
10. Go to HWMonitor official site
11. scroll to download section
12. click setup (installer version)
13. Open and follow setup

---

## Verification

- Confirm HWMonitor appears under Installed Programs.
- Launch HWMonitor successfully.
- Verify that hardware sensor information is displayed.
- Compare available information with Windows Task Manager and System Information.
