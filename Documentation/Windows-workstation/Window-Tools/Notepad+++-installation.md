# Installing Notepad+++ onto Workstation

## Objective / Purpose

- Install Notepad++ as a standard text editing utility within the Windows lab environment.
- Develop familiarity with enterprise-approved productivity tools used for editing configuration files, scripts, logs, and documentation.
- Practice documenting application installation and validation procedures.

---

## Prerequisites

- Windows client or server operating system installed and operational
- Local administrator account access
- Internet access to download the installer
- Approved software source for obtaining the installation package

---

## Environment

Host: MacBook Air (M2, 8 GB RAM)  
Client: Windows 11 Pro ARM Virtual Machine  
Server: None (planned for future phases)  
Cloud: None

OS:

- Windows 11 Pro ARM

Tools:

- Notepad++
- Windows Settings
- Control Panel
- File Explorer

---

## Procedure

1. Download the appropriate Notepad++ installer package for Windows.
2. Run the installer with administrator privileges.
3. Accept the license agreement.
4. Select the installation directory and required components.
5. Complete the installation wizard.
6. Launch Notepad++ from the Windows Start Menu.
7. Configure preferences if required:
    - Default language settings
    - File associations
    - Editor preferences

## Issues

- Some enterprise environments may require approval before installing third-party text editors.
- File associations may require manual configuration.
- Plugins should be reviewed before installation in production environments due to security and compatibility concerns.
- ARM compatibility should be verified when using Windows ARM virtual machines.
