# Installing 7-zip onto Windows 11 Workstation

## Objective
- Install 7-Zip as a standard utility for managing compressed files within the Windows lab environment.
- Gain hands-on experience installing and validating third-party software on Windows client and server systems.
- Practice documenting software deployment tasks similar to an enterprise IT environment.

---

## Prerequisites
- Windows client or server operating system installed and operational
- Local administrator account access
- Internet access to download the installer
- Approved software source for obtaining the installation package

---

## Environment
Host: MacBook Air (M2, 8 GB RAM)
Client Windows 11 Pro ARM Virtual Machine
Server:None (planned for future phases)
Cloud: none
OS: Windows 11 Pro ARM
Tools:

---
## Procedure

1.  Open browser in Windows
2. Go to 7-zip.org 
3.  Download
	1. find download section
	2. select windows
	3. Select ARM64 option
	4. use x64 if only one availible
	5. Click download
4.  Open installer
	1. Select download icon in edge
	2. Select 7-Zip file
	3. Select Install, wait, then close

---


## Verification
1. Right click Windows desktop
2. Look for 7-Zip
	1. If there then good!
--- 
## Issues
- Windows 11 ARM may have compatibility differences compared to traditional x64 Windows systems.
- Enterprise environments may require software approval before installation.
- File association settings may need to be configured manually.
- Older versions of 7-Zip should be avoided due to potential security vulnerabilities.
